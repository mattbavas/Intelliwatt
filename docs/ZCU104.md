# ZCU104 implementation next steps

1. Confirm the physical board revision and FPGA marking. The starter targets
   xczu7ev-ffvc1156-2-e; verify this against the board before implementation.
2. Select a PL clock source using the AMD ZCU104 User Guide (UG1267) and board
   schematic. Record its frequency, pin pair/single pin, bank voltage, and
   I/O standard. A PS-generated PL clock requires a PS block design and its
   initialization flow; the generic core alone does not configure the PS.
3. Add rtl/zcu104_top.sv as the board wrapper. Instantiate appropriate clock
   input primitives for the selected source. Synchronize asynchronous switches
   and buttons with marked synchronizer registers. Debounce buttons if used
   as events; arrange reliable reset at startup (e.g. a held board reset).
   Feed synchronous rst and enable to intelliwatt_top, map heartbeat to an LED.
4. Copy the XDC template to a verified XDC. Map every wrapper port using the
   schematic, constrain the actual input clock, and document polarity. Add
   I/O timing constraints or narrowly justified asynchronous exceptions.
   Never suppress UCIO-1 or NSTD-1 to force bitstream generation.
5. Update scripts/build.tcl to read the wrapper and set its synthesis top;
   retain the portable core testbench and add wrapper-specific checks.
6. Run simulation and synthesis, then implementation. Review DRC, clocking,
   timing checks, setup/hold timing and unconstrained paths. The script checks
   reported negative slack, but engineering review of constraint completeness
   is required before programming hardware.
7. Program the resulting .bit through Vivado Hardware Manager/JTAG. Verify
   reset, enable/hold and LED heartbeat. Save the Vivado version, verified XDC,
   build reports, board revision and observed results. No board test or
   generated bitstream is claimed by this starter.
8. Add activity counters and a programmable sampling/policy module with
   tests. Choose a control interface (AXI-Lite or a standalone interface)
   after defining the demo requirements; PS/AXI is optional for the first LED demo.

Official reference: https://docs.amd.com/r/en-US/ug1267-zcu104-eval-bd
Use the document and schematic matching your board revision.
